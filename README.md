# Projet_Deep_Learning_Galaxies
Tâche de classification à partir d'une base de données d'images

Choix du projet :

dataset et tâche : ceux-ci doivent être peu étudiés (dataset construit pour le projet, agrégation de données existantes, utilisation d'un dataset existant mais pour une tâche différente) ; les datasets présents sur kaggle (ou toute autre plateforme similaire) sont déconseillés, sauf utilisation originale ;
construction et pré-traitement du dataset : les difficultés liées à la construction et le nettoyage du dataset et à la conception de la tâche seront valorisées lors de l'évaluation ;
utilisation du Deep Learning : l'approche du problème devra nécessairement inclure du Deep Learning, en particulier ce qui a été vu en cours. Seront appréciés les projets mettant en valeur : une utilisation originale de la backprop, les VAE, les LSTM, les Transformers, ou des architectures originales construites à l'aide des briques vues en cours ;
utilisation du Machine Learning classique : l'utilisation de méthodes de Machine Learning classique (régression linéaire, k-NNs, random forests, etc.) est conseillée, au moins à titre de comparaison ;
autres méthodes de Deep Learning : l'utilisation de méthodes de Deep Learning non vues en cours est possible, à condition de les expliquer en annexe du rapport, et d'être capable de répondre à des questions sur celles-ci à l'oral.
Conduite du projet :

train et test sets : leur usage est obligatoire pour évaluer les résultats ;
résultats : plusieurs modèles (de complexité croissante) devront être testés, et leurs résultats rapportés dans un tableau ;
méthodes existantes : il est conseillé de chercher dans la littérature scientifique ou technique les méthodes de Machine Learning/Deep Learning habituellement utilisées pour le dataset et la tâche choisis.
